TraceTrade: Product Requirements

Scope said "shows exactly what each trade was based on." Now we know exactly what that means: an expandable receipt per decision with numbered sources and a rule-by-rule check.

Core journey

$FLOW
  1. Open dashboard: \$10,000 cash, 8-asset watchlist, empty log, Run agent.
  2. Click Run → live trace: Gathering → Reasoning → Self-check → Executing.
  3. Per asset: headlines, price, Polymarket odds.
  4. Agent proposes BUY/SELL/HOLD + size + confidence, citing sources.
  5. Self-check → Approved / Resized / Blocked.
  6. Paper portfolio updates; blocked trades change nothing.
  7. Decision cards expand to show receipts.

Screen layout proposed

Behaviors & criteria

Running the agent
  • Button disables, trace shows steps
  • Run over 8 assets < ~60 s, ends with summary "2 approved · 1 resized · 1 blocked · 4 hold"
Signals
  • Price + 24h change, up to ~5 headlines, Polymarket odds or "no market found"
  • Every signal: source, link, age
Decision card & receipts proposed fields

Card: time · ticker · action · size (\$ and %) · confidence · thesis · verdict.
Receipts: reasoning with [1][2] citations · numbered sources · check table · fill price & position.

Self-check rules proposed thresholds
RuleFails whenOutcome
Max position> 20% of portfolioRESIZE
Source independence< 2 independent sourcesBLOCK
Freshnessprice > 15 min or headlines > 48 hBLOCK
CashBUY > cashRESIZE / block if < \$100
Holding existsSELL without positionBLOCK
Market hoursstock trade while closedfill at last close, amber flag
Blocked example: red border, BUY NVDA \$4,000: "Blocked: only 1 independent source"
Resized example: "proposed \$3,000 → executed \$2,000 (max position 20%)"
Portfolio
  • Starts \$10,000; updates after fills
  • Reset with confirmation clears log

States

First use · Running · Partial data · Failure · All HOLD · Persistence
  • First use: "No decisions yet. Run the agent…"
  • Running: button disabled
  • Partial data: run continues, missing source named
  • Failure: clear message, portfolio untouched
  • All HOLD: "No trades this run" + reasons
  • Persistence proposed: same device until Reset

Look & feel proposed

Dark terminal, monospace numbers, colour = meaning (green approved, red blocked, amber resized, grey hold). No purple-gradient AI styling.

Deferred / Non-goals

Show

Deferred: scheduled runs, social sentiment, editable rules, charts, accounts.
Non-goals: real money, financial advice, options/leverage/shorting, paid feeds.
