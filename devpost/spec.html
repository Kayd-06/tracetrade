TraceTrade: Technical Spec

The AI proposes, the rules decide. One Next.js app, one streaming route, no database; portfolio lives in your browser.

Architecture

Journey stepper

Step 1

Open page → load portfolio from localStorage, fetch /api/prices

Step 2

Click Run → POST portfolio to /api/run

Step 3

Route fetches 8 assets' signals in parallel → streams step events

Step 4

Per asset: LLM returns JSON decision citing source IDs (zod-validated)

Step 5

selfCheck() → approved / resized / blocked + rule table

Step 6

Browser applies fills, saves localStorage, renders card

Step 7

done event → run summary

Failure modes

Show
  • Yahoo blocked → stocks HOLD "price unavailable", crypto continues
  • LLM fails → retry once, then HOLD; all fail → message, portfolio untouched
  • No Polymarket market → shown missing; may trigger block
  • Timeouts → parallel calls, 10 s each, streaming
